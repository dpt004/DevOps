# File mẫu import sinh viên

Các file CSV trong thư mục này có thể mở bằng Excel và import trực tiếp từ giao diện hệ thống.

Quy tắc import:

- Người dùng phải chọn lớp trước khi import.
- Mỗi file nên chứa sinh viên của một lớp.
- Khi import từ UI, hệ thống ưu tiên lớp đang chọn để tránh cộng dồn nhầm sang lớp khác.
- Các cột được hỗ trợ: `MSSV`, `Họ tên`, `Lớp`.

File mẫu:

- `d21cqcn01.csv`
- `d21cqcn02.csv`
- `d22cqcn01.csv`
